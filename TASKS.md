## 🌿 Регламент ветвления Git

> [!WARNING]
> Любое прямое внесение сетевого кода в ветки `main` или `dev` нарушает изоляцию классической оффлайн-версии викторины.

### Пошаговый сценарий работы над задачей или багом:

1. **Переключение на базовую ветку и подтягивание обновлений:**
   ```bash
   git checkout feature/online-multiplayer
   git pull origin feature/online-multiplayer
   ```

2. **Создание тематической ветки:**
   ```bash
   # Для новой фичи / редизайна:
   git checkout -b task-04-host-screen

   # Для исправления бага:
   git checkout -b fix/<bug-name>
   ```

3. **Разработка и обязательное прохождение автотестов:**
   ```bash
   npm.cmd test
   cd server; npm.cmd test; cd ..
   ```

4. **Слияние строго обратно в `feature/online-multiplayer`:**
   ```bash
   git checkout feature/online-multiplayer
   git merge task-04-host-screen --no-ff
   ```

5. **Обновление статуса в [TASKS.md](file:///C:/Users/user/IdeaProjects/quiz_u/TASKS.md) и [ROADMAP.md](file:///C:/Users/user/IdeaProjects/quiz_u/ROADMAP.md).**

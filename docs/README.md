# 🏙️ Викторина «Город Ю» (Quiz U)

Браузерная командная викторина: локальная игра за одним экраном на ПК или телефоне и LAN-игра со смартфонами в роли игроков и ведущего. Для локального режима на телефоне уже предусмотрен адаптивный дизайн. Нативные приложения Android/iOS не разрабатываются; Steam/Tauri — следующий этап.

## 🚀 Основные возможности

### 1. Игровой процесс и механики
- **400+ готовых паков вопросов**: мультфильмы, кино, сериалы, музыка, видеоигры, наука, история, литература, мемы и многое другое.
- **Интерактивный каталог паков**:
  - Мгновенный поиск по названиям, описанию, тегам и темам;
  - Фильтры по категориям, уровням сложности (Просто, Средне, Сложно, Очень сложно) и числу раундов (1, 2, 3 раунда, с финалом / без финала);
  - Быстрый предпросмотр всех тем раунда и скачивание пакета как автономной HTML-страницы с вопросами и ответами.
- **Специальные типы вопросов**:
  - **«Кот в мешке»**: передача вопроса сопернику с анимацией кота;
  - **«Аукцион» (для всех / только для лидера)**: динамические ставки, повышение, пас и ва-банк;
  - **Мультимедиа**: встроенная поддержка аудио (MP3/OGG), видео (MP4/WebM), изображений и математических формул (KaTeX).
- **Очередность ходов** (настройка «⚙️ Настройки игры»):
  - **«По очереди»** (по умолчанию): после каждого вопроса право выбора переходит следующей команде; новый раунд тоже передаёт ход;
  - **«Ходит ответивший верно»**: выбирает следующий вопрос команда, ответившая верно (при нескольких — первая зачтённая); если никто не ответил верно — ход остаётся у выбиравшего;
  - ведущий в любой момент передаёт ход вручную («🔄 Передать ход»).
- **Финальный раунд** (последний раунд «Финал» или раунд с `"isFinal": true`): отдельный экран «🏆 Финал», один вопрос на тему (при нескольких темах ведущий выбирает одну). Играют только с положительным счётом; тайная ставка от 1 до своих очков; пасовать нельзя; на ответ 60 с.
- **Настраиваемые таймеры**: отдельное конфигурирование времени на чтение, размышление и ответ.
- **Темы оформления**: тёмная (ночной город) и светлая (солнечный день) темы с плавной анимацией и звёздами.

### 2. Онлайн-мультиплеер в стиле Jackbox (Host + Mobile Web-Buzzer)
- **Ведущий (Host)** открывает комнату на большом экране (ПК, проектор, ТВ). Сервер генерирует пятибуквенный код и динамический QR-код.
- **Игроки** сканируют QR-код смартфоном или открывают ссылку в браузере мобильного, вводят имя, выбирают аватар и мгновенно подключаются.
- **Сверхбыстрый арбитраж баззера**:
  - Гонка ответов с авторитетным серверным арбитражем (средняя задержка **~20–25 мс**);
  - Тактильная виброотдача (Haptic Feedback) на мобильном при открытии и нажатии баззера;
  - Режим ввода ответа с мобильного или озвучивания голосом ведущему;
  - Мобильный интерфейс для ставок аукциона и передачи кота в мешке.
- **Очередность ходов на сервере**: сервер ведёт очередь выбора вопроса; на телефонах «👉 Ваш ход!» или «Вопрос выбирает: имя».
- **Финал по сети**: без баззера. Ставки делаются на телефонах, ведущий закрывает их (на телефоне или на ПК). Ответы вводятся текстом (60 с или пока не ответили все), видит их только ведущий и судит каждый по отдельности; вердикты и правильный ответ показываются на общем экране.
- **Anti-Cheat**: ответы на вопросы (`a`, `a_img`) изолированы и никогда не передаются на клиенты игроков.
- **Устойчивость к обрывам**: автоматический reconnect и восстановление игровой сессии по токену.

### 3. Мобильный пульт Ведущего (Host Remote Control)

Ведущему **не нужно находиться рядом с ПК/ТВ** — все кнопки управления игрой находятся у него на телефоне:

| Кнопка | Действие |
|:---|:---|
| 🟢 **Засчитать ответ (+очки)** | Начисляет очки давшему верный ответ |
| 🔴 **Отклонить ответ (-очки / без вычета)** | Судейство ответа: отклонение без штрафа либо со штрафом с повторным открытием базера |
| 🏁 **Следующий раунд** | Переход к следующему раунду после окончания текущего (`ROUND_END`) |
| 📊 **Показать статистику** | Вывод финальной статистики и экрана победителей на ТВ после окончания игры (`GAME_OVER`) |
| ⏸️ / ▶️ **Пауза / Возобновить** | Останавливает и возобновляет игровой таймер |
| 👁️ **Показать ответ на ТВ** | Раскрывает правильный ответ на главном экране |
| ➡️ **Завершить вопрос / К табло** | Возврат к сетке вопросов |
| 🚀 **Начать игру** | Запуск партии из лобби прямо со смартфона |
| ➕ / ➖ **Ручная корректировка счёта** | Изменение очков любого игрока (+/- 100, а также +номинал / -номинал в карточке игрока) |
| 📋 **Выбор вопроса с телефона** | Интерактивная сетка тем и номиналов для ведущего на смартфоне с автораскрытием на ТВ |
| 🏁 **Завершение игры** | Показ итогов; новая игра доступна в той же комнате |

> [!IMPORTANT]
> Все команды мгновенно синхронизируются через WebSocket-сервер на главный экран ТВ/ПК
> и экраны игроков. Ведущий управляет викториной удалённо.

### 4. Настройки игры в хабе подготовки (Lobby Settings)

Перед запуском партии ведущий настраивает параметры через модальное окно **«⚙️ Настройки игры»**:

| Параметр | По умолч. | Описание |
|:---|:---:|:---|
| Время чтения вопроса | 7 с | При 0 с — мгновенный базер |
| Время обдумывания (окно базера) | 30 с | Минимум 5 с |
| Время ответа после базера | 5 с | Личный таймер; минимум 1 с |
| Штраф за неверный ответ | Выкл | Вкл / Выкл |
| Режим штрафа | — | Номинал вопроса или Фиксированная сумма |
| Очерёдность хода | По очереди | «По очереди» или «Ходит ответивший верно»; сохраняется между запусками |

Настройки передаются через протокол `HOST_UPDATE_ROOM_SETTINGS` / `ROOM_SETTINGS_UPDATED`.

### 5. Валидация старта игры

В сетевом режиме кнопка **«Начать игру»** заблокирована до выполнения условий:

1. В комнате присутствует **ведущий** (с мобильного или на хосте).
2. Подключен **минимум 1 игрок**.

Наглядные бейджи в интерфейсе лобби отображают текущий статус готовности.

### 6. Будущий переход в Steam
Сохранён задел Tauri и модули GamepadManager/SteamIntegration. Они не являются условиями выпуска браузерной версии. Поддержка реального Steamworks backend, нативные сборки и проверка на Steam Deck относятся к следующему этапу. Браузерный Gamepad API доступен с безопасным fallback без Steam.

### 7. Мобильный браузер
- Локальная игра открывается по основному адресу `/` и работает с существующим адаптивным дизайном.
- Для LAN игрок и ведущий открывают `/mobile/` по ссылке или QR-коду комнаты.
- Манифест и иконки веб-пульта сохраняются; установка нативной оболочки не требуется.

### 8. Медиаресурсы и CDN (Cloudflare R2)
- Модуль `CdnManager` с автоопределением и разрешением путей к тяжелым ассетам через CDN.
- Прозрачный автоматический fallback на локальный сервер при сбое сети или недоступности CDN.
- Утилита `scripts/optimize_media.js` для аудита размеров файлов и генерации CDN-манифеста.

## 🎮 Быстрый старт

### Вариант А: Локальная игра на одном экране (оффлайн)
Для локальной игры на одном экране ПК, ноутбука или телефона сборщики и игровой WebSocket-сервер не требуются:
1. Запустите любой локальный HTTP-сервер в корне проекта:
   ```bash
   # Python
   python -m http.server 8000

   # или Node.js npx
   npx serve .
   ```
2. Откройте `http://localhost:8000` на ПК или `http://<IP-ПК>:8000/` на телефоне в той же сети и нажмите **«Локальная игра»**. Для телефона используется адаптивный дизайн основного приложения.

---

### Вариант Б: Сетевой мультиплеер (Jackbox-режим со смартфонами)

1. **Запуск игрового сервера**:
   Перейдите в папку `server/` и установите зависимости (только библиотека `ws`):
   ```bash
   cd server
   npm install
   npm start
   ```
   Сервер запустится на порту `8080` (по умолчанию `http://0.0.0.0:8080`).

2. **Запуск экрана ведущего (Host)**:
   - Откройте в браузере на основном экране: `http://localhost:8080/` (или IP-адрес компьютера в локальной сети `http://192.168.x.x:8080/`).
   - Нажмите **«LAN игра»**.
   - На экране отобразится пятибуквенный код комнаты и QR-код.

3. **Подключение игроков с мобильных телефонов**:
   - Убедитесь, что смартфоны подключены к той же Wi-Fi сети.
   - Отсканируйте камерой QR-код или откройте `http://<IP_КОМПЬЮТЕРА>:8080/mobile/`.
   - Введите код комнаты, имя и нажмите **«Войти в игру»**.
   - Телефон превращается в пульт: при открытии вопроса появляется большая кнопка **«ОТВЕТИТЬ»**.

## 🛠️ Следующий этап: десктоп-версия (Tauri / Steam Deck)

1. Установите Rust и зависимости Tauri:
   ```bash
   # Windows (через winget)
   winget install Rustlang.Rustup

   # Linux / SteamOS
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget libssl-dev libgtk-3-dev
   ```

2. Установите CLI тем же способом, что используется в CI:
   ```bash
   cargo install tauri-cli --version "^2.0.0" --locked
   ```

3. Запуск в режиме разработки будущей desktop-версии:
   ```bash
   npm run dev:desktop
   ```

4. Сборка релизного бинарника (`.exe` / `.AppImage`):
   ```bash
   npm run build:desktop
   ```

## 📱 Игра с телефона в браузере

Откройте основной адрес сервера `http://<IP-ПК>:8080/` на телефоне и выберите «Локальная игра». Это полноценный локальный режим на одном экране с адаптивной вёрсткой.

Для игры несколькими устройствами ПК или телефон открывает LAN-комнату. Участники входят по QR-коду или адресу `http://<IP-ПК>:8080/mobile/?room=КОД`. У игрока открывается баззер, у ведущего — пульт.

Телефон и сервер должны находиться в одной доступной локальной сети. Нативные APK/IPA, Android Studio и Capacitor не нужны.

## ☁️ Оптимизация медиа и настройка CDN

1. **Аудит медиаресурсов**:
   Проверка веса картинок, аудио и видеофайлов с выявлением тяжелых ресурсов:
   ```bash
   npm run optimize:media
   ```
   Скрипт формирует `assets/cdn_manifest.json` со всеми ссылками на удаленный CDN-бакет.

2. **Подключение Cloudflare R2 / Custom CDN**:
   - Загрузите содержимое папки `assets/` в ваш S3 / Cloudflare R2 бакет.
   - В настройках игры или через браузерную консоль укажите базовый URL:
     ```javascript
     CdnManager.setCdnBaseUrl('https://pub-xxx.r2.dev');
     ```
   - При недоступности CDN игра автоматически продолжит брать файлы с локального сервера.

### 📱 Пульт ведущего и сетевая синхронизация (Октябрь 2026)
- **Полное судейство с телефона:** «Зачесть (+cost)», «Отклонить без вычета», «Отклонить с вычетом (-cost)».
- **Управление ходом игры со смартфона:** «Передать ход», «Пропустить раунд», «Прибавить всем очки», выбор вопроса из сетки тем.
- **Гибкая коррекция счёта:** произвольное `+N` / `-N` для любой команды.
- **Единый жёлтый индикатор времени ответа** (`.timer.answering`) в локальной игре и в LAN. Заморозка/снежинка удалены.
- **3+ игроков:** серверный арбитраж баззера, возврат остатка времени размышления остальным игрокам после ошибки.
- **Глобальная пауза:** ручная (ведущий) и автоматическая при отключении участника. Таймеры замораживаются на сервере; авто-пауза снимается, когда все вернулись.
- **Особые вопросы с телефона ведущего:** «Кот в мешке» (назначить отвечающего), аукцион за право ответа (лидер по живым ставкам), аукцион для всех (ответы текстом, судейство по каждой команде).
- **Пас и обязательства:** игрок может спасовать на обычном вопросе; назначенный в «Коте», лидер и участники аукциона обязаны отвечать.
- **Сервер — единственный источник очков:** ПК-хост только отображает `score_updated` и не дублирует начисления.
- **E2E-тесты LAN:** `tests/lan_e2e_container.test.js`, `server/tests/room_lan_fixes.test.js`.
- Все спецификации и трекеры лежат в `/docs/`.

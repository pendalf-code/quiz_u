# Задачи и планы Quiz U

Единственный актуальный трекер. Правила разработки — [AGENTS.md](../AGENTS.md), запуск — [README.md](README.md), проверки ревью — [REVIEW_GUIDE.md](REVIEW_GUIDE.md), завершённая история — [архив](archive/README.md).

## Текущее состояние

- Текущая цель — браузерная игра на ПК и телефонах. На телефоне доступны полноценная локальная игра по основному адресу с существующим адаптивным дизайном и отдельный LAN веб-пульт по /mobile/.
- Нативные Android/iOS-приложения отменены пользователем: Capacitor и Android-проект удалены. Steam/Tauri сохранены для следующего этапа; их нативная сборка не блокирует браузерную версию.
- Текущая ветка — feature/online-multiplayer. Исправления codex/audit-browser-fixes, светлой темы и BUG-78 влиты локально без конфликтов; исходные ветки сохранены. main и dev не затронуты. Онлайн-ветка отправлена в origin по явному запросу пользователя.
- TASK-01…59 завершены. TASK-60: аудит исходников и доступных сценариев завершён с зафиксированными ограничениями. Исходные воспроизведения, восемь фаз и прежние результаты сохранены в [архиве аудита](archive/2026-10/AUDIT_TASK60.md).
- TASK-61: волна исправлений выполнена в 21 отдельной подсессии подагентов с последовательным владением общими файлами. Каждое исходное замечание разобрано отдельно; дополнительно проверен BUG-55 и исправлен обнаруженный в ручном прогоне BUG-77.

## Правила для правки паков (общие для всех под-сессий)

1. Вопрос заканчивается «?» (кроме заданий-императивов «Назовите…» — их переформулировать в вопрос).
2. Вопрос не содержит ответ ни прямо, ни однокоренным словом, ни прозрачным намёком; формулировка однозначна (проверка: `node tools/validate_spoiler_answers.js`).
3. «Что изображено / кто на фото / чей голос / какая мелодия» — только с медиа: `img` (вопрос), `music`, `video`; иначе переписать вопрос в текстовый.
4. Где ответ лучше показать, чем назвать (картина, флаг, животное, логотип, персонаж) — добавить `a_img`.
5. Медиа — только из проверенных источников со свободной лицензией: Wikimedia Commons (PD / CC BY / CC BY-SA), NASA, Openverse, Freesound (CC0). Файл ≤ 500 КБ (картинки — JPG/WebP ≤ 1280 px), имя латиницей, кладём в `assets/q_img/`, `assets/a_img/`, `assets/music/`, `assets/video/`. Источник, автор и лицензия — в `assets/credits/<сессия>.md` (по файлу на сессию, чтобы ветки не конфликтовали).
6. Не трогать `js/packs_catalog.json` и `js/packs_data.js` — их пересобирает координатор.
7. Картинка ответа — поле `a_img` (ПК читает и старое `answer_img`), видео ответа — `a_video`; ключа `audio` нет — только `music`.

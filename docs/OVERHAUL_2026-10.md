## Правила для правки паков (общие для всех под-сессий)

1. Вопрос заканчивается «?» (кроме заданий-императивов «Назовите…» — их переформулировать в вопрос).
2. Вопрос не содержит ответ ни прямо, ни однокоренным словом, ни прозрачным намёком; формулировка однозначна (проверка: `node tools/validate_spoiler_answers.js`).
3. «Что изображено / кто на фото / чей голос / какая мелодия» — только с медиа: `img` (вопрос), `music`, `video`; иначе переписать вопрос в текстовый.
4. Где ответ лучше показать, чем назвать (картина, флаг, животное, логотип, персонаж) — добавить `a_img`.
5. Медиа — только из проверенных источников со свободной лицензией: Wikimedia Commons (PD / CC BY / CC BY-SA), NASA, Openverse, Freesound (CC0). Файл ≤ 500 КБ (картинки — JPG/WebP ≤ 1280 px), имя латиницей, кладём в `assets/q_img/`, `assets/a_img/`, `assets/music/`, `assets/video/`. Источник, автор и лицензия — в `assets/credits/<сессия>.md` (по файлу на сессию, чтобы ветки не конфликтовали).
6. Не трогать `js/packs_catalog.json` и `js/packs_data.js` — их пересобирает координатор.
7. Картинка ответа — поле `a_img` (ПК читает и старое `answer_img`), видео ответа — `a_video`; ключа `audio` нет — только `music`.

# Волна 2 (2026-10-23): сложность по ставке, микс-паки, медиа-вопросы

Исходное состояние: 421 пак, 3058 тем, 14 770 вопросов. Медиа-вопросов почти нет: `img` — 41, `music` — 1, `video` — 0 (картинок-ответов `a_img` — 271). В 2 темах цены идут не по порядку (`200,400,600,800,100`). Медиа в `assets/` — 55 МБ.

## Правила

1. **Сложность растёт со ставкой.** В каждой теме самый простой вопрос стоит меньше всех, самый сложный — дороже всех (100/200 — знает почти каждый, 500/1000/1500 — знает знаток). Сначала переставляем вопросы внутри темы (вопрос переезжает целиком: `q`, `a`, медиа, `type`; цена остаётся за ячейкой), если разброса не хватает — переписываем 1–2 вопроса. Цены в теме идут по возрастанию.
2. **Медиа-вопросы (баланс текста и файлов, решение пользователя 2026-10-23):** 1–2 вопроса с `img` / `music` / `video` на пак (не на раунд), в среднем ≈ 1,5 на пак; бюджет сессии на группу папок — до 200 файлов и 20 МБ. Лишнего не качать. Аудио — гимны, классика в общественном достоянии, голоса животных, звуки природы и техники; видео — NASA, Commons. Вопрос формулируется под медиа («Какой зверь издаёт этот звук?»), медиа не должно подсказывать ответ подписью или водяным знаком.
3. **Бюджет размеров:** картинка ≤ 200 КБ (JPG/WebP, ≤ 1024 px), аудио ≤ 20 с и ≤ 300 КБ (MP3 96–128 кбит/с), видео ≤ 15 с, 480p, ≤ 1,5 МБ и только где без видео нельзя. Источники и лицензии — как в волне 1 (`assets/credits/<сессия>.md`).
4. Остальные правила волны 1 действуют: «?» в конце, без подсказки ответа, факты верны, финал — `roundName` «ФИНАЛ» и тема по смыслу.

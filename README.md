# 🏙️ Викторина «Город Ю»

Интерактивная браузерная командная викторина-квиз (Quiz U) с интерактивным табло вопросов, мультимедиа (картинки, музыка, видео), таймерами раундов, ставками и гибким управлением очками команд для проведения развлекательных мероприятий, корпоративов, уроков и дружеских вечеров.

---

## 🚀 Возможности

- **200+ готовых паков вопросов**: мультфильмы, кино, музыка, игры, наука, история, литература, мемы и многое другое.
- **Удобный каталог паков**:
  - Быстрый поиск по названиям, описанию, категориям и темам;
  - Фильтры по категориям, сложности и количеству раундов (с финалом / без финала);
  - Предпросмотр всех тем раунда и скачивание пакета в формате `.json`.
- **Игровые механики**:
  - Поддержка произвольного числа команд с гибким ведением счета;
  - Специальные типы вопросов: «Кот в мешке» с анимацией и передачей сопернику, «Аукцион» со ставками;
  - Медиавопросы: встроенная поддержка воспроизведения аудио (MP3), видео (MP4) и изображений;
  - Настраиваемые таймеры на чтение вопроса, размышление и ответ;
  - Поддержка темной и светлой темы оформления с анимацией города и звездного неба.

## 📁 Структура проекта

```text
quiz_u/
├── index.html               # Главная точка входа (структура DOM экранов и модалок)
├── css/
│   ├── style.css            # Основные стили викторины (темы, анимации, игровое поле)
│   └── catalog.css          # Стили каталога паков, фильтров и пагинации
├── js/
│   ├── game.js              # Игровой движок (таймеры, команды, раунды, логика викторины)
│   ├── catalog.js           # Логика каталога (поиск, фильтрация, карточки, предпросмотр)
│   └── packs_data.js        # База данных всех доступных паков вопросов (window.AVAILABLE_PACKS)
├── assets/                  # Все статические медиафайлы викторины
│   ├── music/               # Аудиофайлы к музыкальным вопросам (MP3)
│   ├── video/               # Видеофайлы к видеовопросам (MP4)
│   ├── q_img/               # Изображения к вопросам
│   ├── a_img/               # Изображения к ответам
│   └── background.jpg       # Фоновые графические материалы
├── generators/
│   ├── apply_packs.ps1      # Скрипт синхронизации и обновления JSON паков в packs_data.js
│   └── sync_helper.ps1      # Вспомогательный модуль синхронизации паков
└── паки вопросов/           # Исходные файлы паков по категориям в формате JSON
```

## 🎮 Запуск проекта

Проект является полностью статическим веб-приложением и не требует сборщиков (Node.js/Webpack) или внешних зависимостей.

### Вариант 1: Запуск через локальный HTTP-сервер (рекомендуется)
Для корректной загрузки всех медиафайлов браузером запустите любой легковесный HTTP-сервер:
- **VS Code**: расширение *Live Server* -> «Open with Live Server» на `index.html`.
- **WebStorm / IntelliJ IDEA**: правый клик на `index.html` -> *Open in Browser*.
- **Python**:
  ```bash
  python -m http.server 8000
  ```
  и откройте [http://localhost:8000](http://localhost:8000).

### Вариант 2: Прямое открытие в браузере
Просто откройте файл `index.html` в любом современном веб-браузере (Chrome, Firefox, Edge, Safari).

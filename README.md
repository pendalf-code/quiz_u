# 🏙️ Викторина «Город Ю» (Quiz U)

Интерактивная кроссплатформенная командная викторина-квиз с поддержкой локального режима на одном экране, сетевого Jackbox-мультиплеера со смартфонами в роли пультов (Buzzer), сборки для настольных ПК и **Steam Deck** (Tauri), а также мобильного приложения (Capacitor / Android / PWA).

## 🚀 Основные возможности

### 1. Игровой процесс и механики
- **400+ готовых паков вопросов**: мультфильмы, кино, сериалы, музыка, видеоигры, наука, история, литература, мемы и многое другое.
- **Интерактивный каталог паков**:
  - Мгновенный поиск по названиям, описанию, тегам и темам;
  - Фильтры по категориям, уровням сложности (Просто, Средне, Сложно, Очень сложно) и числу раундов (1, 2, 3 раунда, с финалом / без финала);
  - Быстрый предпросмотр всех тем раунда и скачивание пакета в формате `.json`.
- **Специальные типы вопросов**:
  - **«Кот в мешке»**: передача вопроса сопернику с анимацией кота;
  - **«Аукцион» (для всех / только для лидера)**: динамические ставки, повышение, пас и ва-банк;
  - **Мультимедиа**: встроенная поддержка аудио (MP3/OGG), видео (MP4/WebM), изображений и математических формул (KaTeX).
- **Настраиваемые таймеры**: отдельное конфигурирование времени на чтение, размышление и ответ.
- **Темы оформления**: тёмная (ночной город) и светлая (солнечный день) темы с плавной анимацией и звёздами.

### 2. Онлайн-мультиплеер в стиле Jackbox (Host + Mobile Web-Buzzer)
- **Ведущий (Host)** открывает комнату на большом экране (ПК, проектор, ТВ). Сервер генерирует 4-значный буквенный код и динамический QR-код.
- **Игроки** сканируют QR-код смартфоном или открывают ссылку в браузере мобильного, вводят имя, выбирают аватар и мгновенно подключаются.
- **Сверхбыстрый арбитраж баззера**:
  - Гонка ответов с авторитетным серверным арбитражем (средняя задержка **~20–25 мс**);
  - Тактильная виброотдача (Haptic Feedback) на мобильном при открытии и нажатии баззера;
  - Режим ввода ответа с мобильного или озвучивания голосом ведущему;
  - Мобильный интерфейс для ставок аукциона и передачи кота в мешке.
- **Anti-Cheat**: ответы на вопросы (`a`, `a_img`) изолированы и никогда не передаются на клиенты игроков.
- **Устойчивость к обрывам**: автоматический reconnect и восстановление игровой сессии по токену.

### 3. Мобильный пульт Ведущего (Host Remote Control)

Ведущему **не нужно находиться рядом с ПК/ТВ** — все кнопки управления игрой находятся у него на телефоне:

| Кнопка | Действие |
|:---|:---|
| 🟢 **Засчитать ответ (+очки)** | Начисляет очки давшему верный ответ |
| 🔴 **Отклонить ответ (-очки)** | Списывает штраф с повторным открытием базера |
| ⚡ **Открыть базер** | Досрочный ручной запуск окна базера |
| ⏸️ / ▶️ **Пауза / Возобновить** | Останавливает и возобновляет игровой таймер |
| 👁️ **Показать ответ на ТВ** | Раскрывает правильный ответ на главном экране |
| ➡️ **Завершить вопрос / К табло** | Возврат к сетке вопросов |
| 🚀 **Начать игру** | Запуск партии из лобби прямо со смартфона |
| ➕ / ➖ **Ручная корректировка счёта** | Изменение очков любого игрока (+/- 100) |

> [!IMPORTANT]
> Все команды мгновенно синхронизируются через WebSocket-сервер на главный экран ТВ/ПК
> и экраны игроков. Ведущий управляет викториной удалённо.

### 4. Настройки игры в хабе подготовки (Lobby Settings)

Перед запуском партии ведущий настраивает параметры через модальное окно **«⚙️ Настройки игры»**:

| Параметр | По умолч. | Описание |
|:---|:---:|:---|
| Время чтения вопроса | 10 с | При 0 с — мгновенный базер |
| Время обдумывания (окно базера) | 30 с | Минимум 5 с |
| Время ответа после базера | 5 с | Личный таймер; минимум 1 с |
| Штраф за неверный ответ | Выкл | Вкл / Выкл |
| Режим штрафа | — | Номинал вопроса или Фиксированная сумма |

Настройки передаются через протокол `HOST_UPDATE_ROOM_SETTINGS` / `ROOM_SETTINGS_UPDATED`.

### 5. Валидация старта игры

В сетевом режиме кнопка **«Начать игру»** заблокирована до выполнения условий:

1. В комнате присутствует **ведущий** (с мобильного или на хосте).
2. Подключено **минимум 2 игрока**.

Наглядные бейджи в интерфейсе лобби отображают текущий статус готовности.

### 6. Steam & Steam Deck интеграция (Tauri)
- Нативная сборка на Rust + Tauri без тяжелого Chromium.
- Полная поддержка геймпадов (Xbox, DualShock/DualSense, Steam Deck Controller) через Gamepad API.
- Навигация по игровому табло с помощью стиков и крестовины (D-Pad), подтверждение кнопкой `A`, отмена кнопкой `B`.
- Интеграция со Steamworks API (Rich Presence: отображение статуса игры в профиле Steam).
- Разрешение 1280x800 с оптимизированным интерфейсом под экран Steam Deck.

### 7. Мобильная сборка (Capacitor & Android)
- Нативная оболочка на базе **Capacitor 6** для Android и iOS.
- Готовый проект Android Studio в директории `android/`.
- Поддержка режима PWA (Progressive Web App) с манифестом `mobile/manifest.json` и сервисными иконками.

### 8. Медиаресурсы и CDN (Cloudflare R2)
- Модуль `CdnManager` с автоопределением и разрешением путей к тяжелым ассетам через CDN.
- Прозрачный автоматический fallback на локальный сервер при сбое сети или недоступности CDN.
- Утилита `scripts/optimize_media.js` для аудита размеров файлов и генерации CDN-манифеста.

## 🎮 Быстрый старт

### Вариант А: Локальная игра на одном экране (оффлайн)
Для игры на одном ПК или ноутбуке без использования смартфонов сборщики не требуются:
1. Запустите любой локальный HTTP-сервер в корне проекта:
   ```bash
   # Python
   python -m http.server 8000

   # или Node.js npx
   npx serve .
   ```
2. Откройте в браузере `http://localhost:8000` и нажмите **«Локальная игра (один экран)»**.

---

### Вариант Б: Сетевой мультиплеер (Jackbox-режим со смартфонами)

1. **Запуск игрового сервера**:
   Перейдите в папку `server/` и установите зависимости (только библиотека `ws`):
   ```bash
   cd server
   npm install
   npm start
   ```
   Сервер запустится на порту `8080` (по умолчанию `http://0.0.0.0:8080`).

2. **Запуск экрана ведущего (Host)**:
   - Откройте в браузере на основном экране: `http://localhost:8080/` (или IP-адрес компьютера в локальной сети `http://192.168.x.x:8080/`).
   - Нажмите **«Создать онлайн-комнату»**.
   - На экране отобразится 4-значный код комнаты и QR-код.

3. **Подключение игроков с мобильных телефонов**:
   - Убедитесь, что смартфоны подключены к той же Wi-Fi сети.
   - Отсканируйте камерой QR-код или откройте `http://<IP_КОМПЬЮТЕРА>:8080/mobile/`.
   - Введите код комнаты, имя и нажмите **«Войти в игру»**.
   - Телефон превращается в пульт: при открытии вопроса появляется большая кнопка **«ОТВЕТИТЬ»**.

## 🛠️ Сборка десктоп-версии (Tauri / Steam Deck)

1. Установите Rust и зависимости Tauri:
   ```bash
   # Windows (через winget)
   winget install Rustlang.Rustup

   # Linux / SteamOS
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget libssl-dev libgtk-3-dev
   ```

2. Запуск в режиме разработки:
   ```bash
   npm run dev:desktop
   ```

3. Сборка релизного бинарника (`.exe` / `.AppImage`):
   ```bash
   npm run build:desktop
   ```

## 📱 Сборка мобильного приложения (Capacitor / Android)

1. Синхронизация веб-ассетов мобильного пульта в проект Android:
   ```bash
   npm run build:mobile
   ```

2. Открытие проекта в Android Studio:
   ```bash
   npm run cap:open:android
   ```

3. Сборка APK / AAB через Gradle:
   ```bash
   cd android
   ./gradlew assembleRelease
   ```
   Готовый файл APK появится в `android/app/build/outputs/apk/release/`.

## ☁️ Оптимизация медиа и настройка CDN

1. **Аудит медиаресурсов**:
   Проверка веса картинок, аудио и видеофайлов с выявлением тяжелых ресурсов:
   ```bash
   npm run optimize:media
   ```
   Скрипт формирует `assets/cdn_manifest.json` со всеми ссылками на удаленный CDN-бакет.

2. **Подключение Cloudflare R2 / Custom CDN**:
   - Загрузите содержимое папки `assets/` в ваш S3 / Cloudflare R2 бакет.
   - В настройках игры или через браузерную консоль укажите базовый URL:
     ```javascript
     CdnManager.setCdnBaseUrl('https://pub-xxx.r2.dev');
     ```
   - При недоступности CDN игра автоматически продолжит брать файлы с локального сервера.
